# Stage A references

The approved visual design pack is distributed separately as `GuitarTools_StageA_VisualDesign_v1.zip`.
It contains 4 desktop PNG views and standalone static HTML/CSS visual prototypes.

- Tuning Library: central 6-string headstock, side tuning list/editor, charcoal+copper.
- Song Library: dense categorized table and selected-song inspector.
- Tab Player Page layout: track panel left, notation center, controls right, fretboard below.
- Tab Player Horizontal layout: same workspace with horizontally continuous score.

These are *design references only*, not production assets, browser-tested alphaTab output, or editable score sources. Some notation examples originate from user-supplied third-party software screenshots. Do not publish these screenshots as app assets without the appropriate rights. Share the reference ZIP with Astra separately when UI implementation begins.

Stage B needs only the functional requirements in `docs/STAGE_B_ACCEPTANCE.md`; avoid building the polished Stage A UI yet.
